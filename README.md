# charity: water — Small Donation. Life-Changing Impact.

A responsive student landing page translated from the supplied Canva design into semantic HTML, CSS, and JavaScript. The source image is included locally; no build process is required.

## Run in GitHub Codespaces

1. Select **Code → Codespaces → Create codespace on main**.
2. In the terminal, run `python3 -m http.server 8000`.
3. Open the forwarded port labeled **Landing page preview**.
4. Edit `index.html`, `styles.css`, or `script.js`, then refresh the preview.
5. Commit and push changes from Source Control. Stop the Codespace when finished.

## GitHub Pages

Under **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`. Save and wait for the deployment. Submit the published `https://<username>.github.io/charity-water-landing/` URL, not the repository or Codespaces preview.

## Features

- Responsive navigation and layout, arched source photo, and original blue/yellow visual direction.
- Official donation, login, and account-registration destinations.
- Search for relevant page sections and ways to participate.
- Optional browser voice search with graceful typed-search fallback.
- Interactive learning question with feedback and reset.
- Accessible focus styles, semantic headings, alt text, reduced-motion support, and native FAQ disclosure controls.

## Important distinctions

This is an independent student project, not the official charity: water website. Account registration and donations happen on charitywater.org. No payment details or account data are stored here. The decorative five stars match the mockup and are not a review rating. Voice recognition, when supported, uses the visitor's browser service after microphone permission.
